# Roblox chơi trên web (mini game mô phỏng)

Đây là một mini game platform đơn giản phong cách "Roblox-like" chạy bằng HTML/CSS/JS thuần trên trình duyệt.

## Chạy nhanh

```bash
cd roblox-web
python3 -m http.server 8000
```

Mở `http://localhost:8000`.

## Điều khiển

- `WASD`: di chuyển
- `Space`: nhảy
- `Shift`: chạy nhanh
- Nút **Đặt lại vị trí**: reset nhân vật

> Lưu ý: Đây không phải Roblox chính thức, mà là bản mô phỏng gameplay đơn giản chạy web.
